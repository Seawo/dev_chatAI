# AI Roleplay Server

A Python-based AI server that creates immersive roleplay NPCs using NVIDIA Build API.

Designed to work with Unreal Engine, the server manages multiple AI characters, conversation history, character personas, and future AI tools such as TTS and long-term memory.

## Features

- 🤖 NVIDIA Build API Integration
- 🎭 Character Persona System
- 💬 Persistent Conversation Memory
- 📂 JSON-based Character Configuration
- 🔌 Unreal Engine Integration
- 🧠 Multi-NPC Conversation Support
- ⚡ REST API Server

# AI 롤플레잉 서버

NVIDIA Build API를 활용하여 몰입감 넘치는 롤플레잉 NPC를 생성하는 Python 기반 AI 서버입니다.

언리얼 엔진(Unreal Engine)과의 연동을 위해 설계되었으며, 다수의 AI 캐릭터, 대화 이력, 캐릭터 페르소나를 비롯해 TTS 및 장기 기억과 같은 향후 도입될 AI 기능을 관리합니다.

## 주요 기능

- 🤖 NVIDIA Build API 연동
- 🎭 캐릭터 페르소나 시스템
- 💬 지속적인 대화 메모리
- 📂 JSON 기반 캐릭터 설정
- 🔌 언리얼 엔진 연동
- 🧠 다중 NPC 대화 지원
- ⚡ REST API 서버
